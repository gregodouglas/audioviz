# audioviz

A novel desktop music visualizer for Spotify listening. Windows first (RTX-class GPU), macOS second.

Aesthetic direction: spacey, line-based, post-modern / minimal generative art. Not a MilkDrop clone.

## Status

**Phase 0 — research.** See `docs/research/` for the landscape survey and `docs/decisions/` for architecture decision records.

## Layout

- `docs/research/` — research briefs (audio ingest, rendering stack, audio analysis, prior art & aesthetics)
- `docs/decisions/` — ADRs, numbered
